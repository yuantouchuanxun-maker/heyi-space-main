## 当前一句话定位

合一空间以东方美学、真实关系、生命成长与现实落地为核心，建设一个让人能够被看见、被理解、获得陪伴并重新连接自己的空间与生态。

## 当前阶段主线

**合一之家＋素食馆场域＋真实成长内容＋AI工作方式。**

当前先从阿里山大厦的真实场域运营做起，通过空间、素食、活动、直播、内容和产品合作，验证团队能否把理念转化为稳定、可持续、对他人有现实价值的服务。

## 仓库使用原则

- 总仓库存放长期有效的定位、战略、组织和总进度。
- 每个具体项目后续建立独立项目目录或独立仓库。
- 语音直播项目的排班、SOP、复盘和执行记录统一维护在 [`Heyi-Space/heyi-voice`](https://github.com/Heyi-Space/heyi-voice)，本仓库只保留其战略定位、优先级和总进度。
- 已确认的事实直接写入；尚未确认的安排标注“待确认”或“动态调整”。
- 每次更新说明日期、修改内容和下一步行动。
- 重要决策不能只停留在聊天记录中，应沉淀到对应文件。
